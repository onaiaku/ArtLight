# Deliberate divergences from upstream StreamTweak

Every line here is one of *his* added lines that is intentionally **not** in our tree.
`scripts/port-from-streamtweak.sh --check` compares his added lines against ours and flags
anything absent — this file is where each flag gets its reason, so a real miss can never hide
among expected ones.

Rule of the file: if a line is absent and it is **not** listed here, that is a bug. Go port it.

Fork point: his `v8.2.0`. Upstream clone: `~/.hermes/cache/scratch/upstream-streamtweak`.

## Two things to remember about this file

1. **`FoggyBytes.ClipboardSync` is NOT a divergence.** It is in both trees on purpose — his host
   registers it and our ArtMoon client registers it. It is the handshake between the two halves
   of one feature, not branding. The `--check` output should never show it as absent; if it does,
   someone has rebranded it and broken the clipboard.
2. **These are the *only* reasons a flag is allowed to be ignored.** A new absent line with no row
   here means the port is incomplete. That is exactly how the Windows App SDK runtime mismatch was
   caught: `ArtLightControl.csproj` had taken `Microsoft.WindowsAppSDK 2.4.0` through a clean,
   conflict-free merge while `Installer.iss` was skipped entirely and still installed the 2.3
   runtime. Nothing failed. The merge was clean.
