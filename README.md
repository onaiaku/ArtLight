# ArtLight

**One Windows installer for the ArtLight streaming stack.**

- **ArtLight Control** — the host-side control app (live telemetry dashboard, session logs, NVIDIA tuning, game library sync, audio profiles).
- **ArtLight Server** — the stream server (virtual display driver, Playnite sync, frame pacing, web UI). Sources live in [`server/`](server/).

Pairs with [ArtMoon](https://github.com/onaiaku/ArtMoon) on the client.

By onaiaku & Rias.

## Download

Grab the latest installer from the [Releases page](https://github.com/onaiaku/ArtLight/releases).

Windows release binaries (installer, MSI, and bundled executables) are code-signed through the **[SignPath Foundation](https://signpath.org)** — build provenance is verified from this public GitHub repository before signing.

ArtLight does not collect, transmit, or store any user data. All components run locally on your own hardware and network.
