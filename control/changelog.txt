Version 0.1.0 (31/08/2026)
-----------------------------------------------
First public release of ArtLight Control — a host dashboard for your
streaming PC, designed to pair with the ArtMoon client.

✨ FEATURES:

• Live Dashboard — real-time view of your host while streaming: FPS,
  round-trip time, bitrate, frame drops and host latency, refreshed
  every second. When idle, the same panel monitors GPU temperature,
  load, VRAM, CPU and network so you can check the host is cool and
  ready before you start

• Session history — every stream is recorded with quality grades,
  full charts (RTT, latency, host compute), detected games and cover
  art. Compare any two sessions side by side

• Game Library — automatic game detection with high-resolution cover
  art fetched from Steam, GOG, Epic and more. Developer and release
  info included

• Managed apps — add, remove and restart streaming apps from the
  client, with automatic syncing to the streaming server

• NVIDIA Sentinel — snapshot your NVIDIA driver profile and have it
  automatically restored within seconds whenever NVIDIA App resets it

• Link-speed switch — the client negotiates the fastest stable link
  speed before connecting and restores it afterwards, with your
  permission

• Remote power & updates — shut down, restart or install Windows
  updates on the host straight from the client. Ideal for headless
  setups

🔒 SECURITY:

• Authenticated bridge — every client command is signed with the
  client's Moonlight certificate and approved once via a 4-digit PIN.
  Unauthorized devices can still stream, but cannot control the host

ℹ️ NOTES:

• Requires Windows 10 20H1 or later
• Pairs with the ArtMoon client for the full feature set; streaming
  works with any Moonlight-compatible client
