Version 0.1.0 - "The Awakening" (31/08/2026)
-----------------------------------------------

🌙 FIRST RELEASE:
• ArtLight Control is born — our own host dashboard, forked from the
  StreamTweak project and reborn under the ArtLight name with a full
  rebrand: new identity, new icon, new installer art

🎨 BRANDING:
• Every trace of the old name is gone — publisher, links, app identity
  and installer all belong to onaiaku now
• The gold moon: new application icon in the window, the taskbar and
  the installer, with matching installer wizard artwork

🌉 ARTMOON BRIDGE:
• Full compatibility with the ArtMoon client — same bridge protocol
  and port (47998), authenticated pairing, live per-second session
  telemetry (fps, RTT, jitter, drops) on the Dashboard
• Client identity is preserved across the rename, so existing pairings
  keep working

🩹 FIXES:
• Telemetry one-shot bug fixed: every stream now populates the live
  dashboard, not just the first one after a restart
