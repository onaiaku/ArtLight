Version 1.4.0 (01/10/2026)
------------------------------------------------
ArtLight Server 1.4.0 brings the upstream ArtLight 2.0.0 engine in.

PyroWave, a GPU wavelet codec, is available with very low encode and
decode latency. Its frames are independent, so losing one does not
force a new keyframe. It wants a fast wired LAN.

ArtLight's own virtual gamepad driver can now be installed with the
server: Xbox, DualSense, DualShock 4 and Switch Pro emulation with no
ViGEmBus and no licence key. The installer offers it, ticked by
default.

Remote Monitor turns a second device into an additional streamed
display beside your main session. VRR capture is smoother on Windows.
The v2 web UI is now the default interface.

Control is bumped to 1.4.0 in lockstep so Server and Control report the
same version. Control's own code is unchanged in this release.

------------------------------------------------
Version 1.3.1 (27/09/2026)
------------------------------------------------
Startup can no longer be killed by a step it does not need.

A throw from the config-permission repair, or from restoring a pending
NVIDIA Control Panel or RTSS override, used to escape main and abort the
server before it ever started listening. Because logging is barely up at
that point it died with no log at all and a single stderr line nobody
reads, which made it look like the server simply refused to start. Those
three steps are now individually guarded: a failure is logged and startup
carries on.

Startup also records a marker before each step and wraps main, so any
future failure reports what was thrown and how far it got instead of
dying silently.

------------------------------------------------
Version 1.3.0 (26/09/2026)
------------------------------------------------
Eight releases of host-side work in one go — session detection, session
grading, remote power and shared clipboard.

Remote power is the headline: sleep, hibernate or restart the host
straight from the dashboard, with Control asking the host what it can
actually do rather than assuming. Start with Windows now has three modes
— Off, Normal and Priority — and Priority registers a logon task, so
Control is up before anything else on the machine. The clipboard is
shared both ways while you stream, over a key that lasts one stream and
is thrown away at the end; it is off until you switch it on.

Session handling is reworked underneath. Sessions now close by watching
the stream's own sockets instead of matching text in the log, which is
what let a finished session stay marked live. Grading is split at
reconnects and scored per segment, with a clock axis on the charts, so a
mid-session blip no longer colours the whole run — and one bad frame no
longer decides a long session. The "Excellent" grade needs a 0.6 frame,
up from 0.5. VRAM no longer double-counts shared graphics memory.

Everything in this release is host-side. ArtMoon needs no update to use
any of it.

Version 1.2.2 (08/09/2026)
------------------------------------------------
Start with Windows is now enabled by default — the installer adds a
checked "Start ArtLight Control when Windows starts" option which
launches the app minimized to the system tray (no window at boot).
Untick it during setup to opt out; your choice is remembered on
upgrades. The in-app Settings toggle works as before.

Version 1.2.1 (08/09/2026)
------------------------------------------------
Version parity release — Control is bumped to 1.2.1 in lockstep with
ArtLight Server 1.2.1 so both report the same version. No Control
functionality changes in this release.

Version 0.1.0 (31/08/2026)
-----------------------------------------------
First public release of ArtLight Control — a host dashboard for your
streaming PC, designed to pair with the ArtMoon client.

✨ FEATURES:

• Live Dashboard — real-time view of your host while streaming: FPS,
  round-trip time, bitrate, frame drops and host latency, refreshed
  every second. When idle, the same panel monitors GPU temperature,
  load, VRAM, CPU and network so you can check the host is cool and
  ready before you start

• Session history — every stream is recorded with quality grades,
  full charts (RTT, latency, host compute), detected games and cover
  art. Compare any two sessions side by side

• Game Library — automatic game detection with high-resolution cover
  art fetched from Steam, GOG, Epic and more. Developer and release
  info included

• Managed apps — add, remove and restart streaming apps from the
  client, with automatic syncing to the streaming server

• NVIDIA Sentinel — snapshot your NVIDIA driver profile and have it
  automatically restored within seconds whenever NVIDIA App resets it

• Link-speed switch — the client negotiates the fastest stable link
  speed before connecting and restores it afterwards, with your
  permission

• Remote power & updates — shut down, restart or install Windows
  updates on the host straight from the client. Ideal for headless
  setups

🔒 SECURITY:

• Authenticated bridge — every client command is signed with the
  client's Moonlight certificate and approved once via a 4-digit PIN.
  Unauthorized devices can still stream, but cannot control the host

ℹ️ NOTES:

• Requires Windows 10 20H1 or later
• Pairs with the ArtMoon client for the full feature set; streaming
  works with any Moonlight-compatible client
