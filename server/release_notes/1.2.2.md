# ArtLight 1.2.2 - 2026-09-08

Developed by onaiaku & Rias.

## Changed

- **ArtLight Control now starts with Windows by default.** The Control installer adds the autostart entry during setup (launching minimized to the system tray, never opening a window at boot). The setup wizard shows a "Start ArtLight Control when Windows starts" option — untick it if you'd rather launch manually, and your choice is remembered on future upgrades. The in-app Settings toggle still works exactly as before, and uninstalling removes the entry.

## Fixed

- **Release downloads are the real combined installer again.** 1.2.0 and 1.2.1 shipped a Control-only installer under the `ArtLight.Setup.exe` name because the release pipeline skipped its packaging step. The pipeline now always builds the full package — server MSI with Control chained inside — so one download installs everything.

## Notes

- Control is bumped to 1.2.2 in lockstep so Server and Control report the same version.
- Windows Defender may flag the download as unsafe, Windows doesn't know what ArtLight is yet
- Code signing via SignPath Foundation is being set up; until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
