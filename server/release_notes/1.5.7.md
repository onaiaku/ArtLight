# ArtLight 1.5.7 - 2026-10-15

Developed by onaiaku & Rias.

## Added

- **The Linux installer offers the reboot it asks for.** When a step leaves the machine needing a reboot, the installer now says so and reboots on Enter, instead of printing the step and leaving you to do it yourself. Anything other than Enter leaves the machine alone.

## Fixed

- **Updating ArtLight on Linux can no longer leave the graphics card unable to start.** The display driver could hold the card in a state the next boot was unable to recover from, so the GPU failed to initialise and the machine fell back to integrated graphics until it was restarted again.
- **The ArtLight package repository works on a first install.** Setting it up wrote the repository into the package manager's configuration but never fetched its database, so the install fell back to a downloaded package and the repository sat there updating nothing.
- **On systems with Secure Boot, the display driver is now signed with a key the firmware trusts.** The signing key was never offered to the machine, so the driver could not be trusted even when it was signed.

## Notes

- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
