# ArtLight 1.2.0 - 2026-09-07

Developed by onaiaku & Rias.

## Fixed

- **Session closure orphan rescue + full chain logging.** Streams that ended abnormally no longer leave orphaned session state behind; the full close chain is now logged end-to-end, so a stuck session can be diagnosed from the log alone. (42cb4f97)
- **EndSession crash: duplicate game names killed the cover snapshot.** When two library entries shared a name, EndSession failed while capturing the cover snapshot, leaving the session record incomplete. Deduplication now handles the collision and the snapshot survives. (92690bf6)

## Notes

- Control's version is stamped from the server's CMakeLists at build time, so Control and Server now report 1.2.0 together.
- Windows Defender may flag the download as unsafe, Windows doesn't know what ArtLight is yet
- Code signing via SignPath Foundation is being set up; until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
