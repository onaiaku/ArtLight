# ArtLight 1.5.1 - 2026-10-09

Developed by onaiaku & Rias.

## Fixed

- **The virtual gamepad driver is installed again.** It was missing from 1.5.0, so no virtual controller could be created and controller input never reached a stream. The installer now carries it and installs it as part of setup. It is offered on the install screen, ticked by default.

## Notes

- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
