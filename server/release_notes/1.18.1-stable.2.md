# ArtLight Server 1.18.1-stable.2 - 2026-07-22

Notice: ArtLight Server may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/onaiaku/ArtLight/issues/29

## Changes
- ArtLight Server is now sponsored by SignPath for Windows code signing. Free code signing is provided by SignPath.io, with the certificate issued to SignPath Foundation. Windows can now verify the publisher and the release's connection to the ArtLight Server repository, which should reduce false-positive antivirus detections and Smart App Control warnings.

## Fixes
- Included several bug fixes. More specific changes are available in the changelog built into the Web UI dashboard.
