# ArtLight 1.4.0 - 2026-10-01

Developed by onaiaku & Rias.

## Added

- **PyroWave, a GPU wavelet codec with very low encode and decode latency.** Frames are independent, so losing one does not require a new keyframe. Supports SDR and HDR, 8-bit and 10-bit colour, and 4:2:0 and 4:4:4 profiles where the GPU and capture path allow. It needs a fast **wired LAN** with hundreds of Mbps available. H.264, HEVC and AV1 streaming are unchanged and still there.
- **ArtLight Server's own virtual gamepad driver.** Xbox Series, Xbox One, DualSense, DualShock 4 and Switch Pro emulation without ViGEmBus and **without any licence or licence key**. Rumble, impulse triggers, touchpad, motion sensors, battery reporting, lightbar and adaptive triggers are supported where the selected profile, client and game support them. The Windows installer offers it as an option, on by default; select `vhf` in the Web UI for automatic controller selection.
- **Remote Monitor and Remote Input.** Launch Remote Monitor from Moonlight on another device to turn it into an additional, independently streamed display beside your main session, up to four clients. Remote Input attaches a client for control with no video.
- **ArtLight Server on Linux.** Arch Linux and CachyOS are supported, with an install script and a package. The virtual display driver builds as a kernel module for the kernel you are running, and the systemd units, udev rules and uinput rules are installed for you. Re-running the installer is safe — it only installs what is missing — and it tells you whether a reboot is needed.
- **A changelog panel in the Web UI**, so you can see what changed without leaving the dashboard.

## Changed

- **The v2 Web UI is now the default interface.**
- **VRR capture is smoother.** Windows Graphics Capture timing now follows game presentation more closely, including uneven callbacks. VRR playback needs a Moonlight client that requests VRR pacing — that request automatically selects a fixed 1000 Hz virtual-display mode, so newly presented frames are captured promptly without raising the stream frame rate.

## Fixed

- Remote Monitor and Remote Input sessions are preserved when games end, while the game's virtual displays and runtime settings are released.
- Stale virtual gamepad reports no longer replay released buttons and triggers.
- Installer actions stay reachable on smaller Windows screens, and WebRTC source cleanup is protected from drive-root paths.
- Steam artwork synchronisation works again when a valid PNG does not need transcoding.

## Notes

- Control is bumped to 1.4.0 in lockstep so Server and Control report the same version. Control's own code is unchanged in this release.
- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
