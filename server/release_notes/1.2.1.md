# ArtLight 1.2.1 - 2026-09-08

Developed by onaiaku & Rias.

## Fixed

- **Dashboard changelog now stays current without manual refreshes.** The Overview changelog panel was hitting GitHub's unauthenticated API rate limit (60 requests/hour, shared across every visit and device), which is why the release list usually only appeared after hitting Refresh. GitHub release data is now cached locally for 30 minutes, so the panel populates on load instead of silently falling back to the bundled copy.

## Added

- **Download button for new builds.** When a newer ArtLight release is available, the changelog panel now shows an "Update available" banner with a direct **Download latest build** button (straight to the installer asset) and a link to the release page — no more detour through GitHub to fetch the installer. The banner only appears when the installed version is actually behind.
- **Manual refresh always hits GitHub live.** The Refresh button in the changelog panel bypasses the new cache, so checking for a fresh release is always a real check.

## Notes

- Control is bumped to 1.2.1 in lockstep so Server and Control report the same version.
- Windows Defender may flag the download as unsafe, Windows doesn't know what ArtLight is yet
- Code signing via SignPath Foundation is being set up; until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
