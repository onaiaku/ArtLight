# ArtLight 1.6.1 - 2026-11-07

Developed by onaiaku & Rias.

## Added

- **Fedora 45.** Fedora 45 ships OpenSSL 4.0, which made two structures the certificate code reads from private, so the server would not compile on 45 even though Fedora 43 and 44 built 1.6.0 cleanly. The code now asks OpenSSL for the same values through its public calls, which works on every version we build for, and Fedora 45 has a package of its own.

## Fixed

- **A retained second screen can no longer outlive the app that asked for it.** A Remote Monitor held for resume used to survive the app it was showing: when the app exited with the monitor connected, the release skipped it as still capturing, the monitor's own transport then ended, and nothing asked again. Both the virtual display and the display revert were left pending, and the next launch inherited a display whose owner no longer existed — which could fail to replace it and answer 503 when the monitor tried to connect. When the last transport ends and no app is running, the retained monitor is released before the session finalizes.
- **Removing a virtual display now puts the desktop back where it was.** A cleanup that removed a display and skipped the enforced revert left the desktop wherever the removal had put it, with monitors coming back side by side instead of in their own arrangement. The saved display layout is restored whenever a display was actually removed.
- **The installer and Control now report the same version as the server.** 1.6.0 shipped with the server at 1.6.0 while the installer and Control still carried 1.5.7, so Add/Remove Programs and the app disagreed with the version actually running. All of them carry 1.6.1 together.

## Notes

- An existing second screen from 1.6.0 is released on the first launch of 1.6.1 rather than being carried over.
- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
