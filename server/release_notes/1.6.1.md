# ArtLight 1.6.1 - 2026-11-06

Developed by onaiaku & Rias.

## Fixed

- **The Fedora package builds and ships again.** The RTX HDR runtime is a prebuilt set of NVIDIA libraries, and they carried the CUDA toolkit path of the machine they were built on. That path exists on nobody else's computer, and Fedora's packaging check refuses a package that contains one — so 1.6.0 built all 866 files and was then thrown out at the door on both Fedora 43 and Fedora 44. The libraries now point at the directory they actually live in, which is where they were always being loaded from.
- **ArtLight Control and the Windows installer agree with the server about what version they are.** 1.6.0 shipped a server reporting 1.6.0 with Control and the installer still labelled 1.5.7, which made the update path argue with itself. All of them now say 1.6.1.

## Added

- **Fedora 45.** It joins Fedora 43 and 44 as a build target. Like 44, it needs GCC 14 pulled from Fedora 43's repositories, because CUDA 12.9 will not accept a newer host compiler and Fedora 45 ships GCC 16.

## Notes

- Fedora packages come from the Copr project, not from Fedora's own repositories: `sudo dnf copr enable onaiaku/artlight` then `sudo dnf install artlight`.
- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
