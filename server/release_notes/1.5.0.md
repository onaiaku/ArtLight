# ArtLight 1.5.0 - 2026-10-04

Developed by onaiaku & Rias.

## Added

- **USB device sharing.** A keyboard, mouse or controller plugged into the PC you are streaming from can be moved onto this PC for the length of a session, and handed back when the session ends. The machine you stream from decides which of its devices are offered; this side decides whether to take what is offered, and it does so by default. Nothing moves unless that machine is offering a device, which only happens at the moment somebody there shares one. A device taken this way is away from the machine it is plugged into for the length of the session, so if you would rather this PC never reached for an offered device, turn it off in the Web UI under **Settings → Input → Input Devices**.

- **The client is installed for you.** On Windows the USB/IP client is bundled in this installer behind a tick box, and it is removed again when ArtLight is uninstalled. On Linux the package installs the privileged helper, the polkit action and the `vhci-hcd` kernel module, and the installer tells you if any of them is missing.

## Changed

- Devices held by a session are given back on every way a session can end, including a crash or a stop racing a start, rather than only on a clean stop.
- A device that was already attached before the session started is left alone — it is not this session's to release.
- Toggling a device in the Web UI now says so when the request was refused, instead of silently doing nothing.

## Fixed

- The Linux package depended on a package name that does not exist on Arch (`usbip-utils`), so the install could not resolve. It is `usbip`.
- The Windows input service could never create its named pipe — `PIPE_REJECT_REMOTE_CLIENTS` was passed in the wrong argument to `CreateNamedPipeW`, so every call failed with `ERROR_INVALID_PARAMETER` and the pipe never existed.

## Notes

- **This is the first release carrying the importer half.** Stated plainly: the code path exists and the packaging installs it, but a stream moving a device has not been run on hardware at the time of writing. USB sharing ships off, so installing this release changes nothing until the switch is turned on.
