# ArtLight 1.5.0 - 2026-10-04

Developed by onaiaku & Rias.

## Added

- **USB device sharing.** A keyboard, mouse or controller plugged into the PC you are streaming from can be moved onto this PC for the length of a session, and handed back when the session ends. The machine you stream from decides which of its devices are offered, and only at the moment somebody there chooses to share one. This PC takes what is offered by default; turn it off in the Web UI under **Settings → Input → Client input**.
- **The USB/IP client is installed for you.** On Windows it comes bundled in this installer behind a tick box, and is removed again when ArtLight is uninstalled. On Linux the package installs the privileged helper, the polkit action and the `vhci-hcd` kernel module, and tells you if any of them is missing.

## Fixed

- **Devices are given back on every way a session can end** — a clean stop, a crash, or a stop racing a start — instead of only on a clean stop.
- **A device that was already attached before the session started is left alone**, rather than being released along with the session's own.
- **The Linux package asked for a dependency that does not exist on Arch** (`usbip-utils`), so the install could not resolve. It is `usbip`.
- **The Windows input service could never create its named pipe.** `PIPE_REJECT_REMOTE_CLIENTS` was passed in the wrong argument to `CreateNamedPipeW`, so every call failed with `ERROR_INVALID_PARAMETER` and the pipe never existed.
- **Toggling a device in the Web UI now says so when the request was refused**, instead of silently doing nothing.

## Notes

- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
