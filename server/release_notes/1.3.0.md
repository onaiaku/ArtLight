# ArtLight 1.3.0 - 2026-09-26

Developed by onaiaku & Rias.

## Added

- **Remote power — sleep, hibernate or restart the host from the dashboard.** Control asks the host what it can do and offers exactly those options, so a machine can be shut down or brought back without walking to it. What is supported is reported by the host itself, not assumed by the dashboard.
- **Shared clipboard.** Text copied on the host pastes on the client and the other way round while you stream, over a key that lasts one stream and is discarded at the end. Off until you turn it on, and the host can refuse from its own switch.
- **Start with Windows now has three modes — Off, Normal and Priority.** Priority registers a logon task rather than a plain startup entry, so Control is up and listening before anything else on the machine.

## Changed

- **Session grading reworked, with a clock axis on the charts.** Sessions are split at reconnects and graded per segment instead of as one run, so a mid-session blip no longer colours the whole session.
- **The "Excellent" grade now requires a 0.6 frame, up from 0.5.**

## Fixed

- **Sessions could stay marked live after they had ended.** Closure now watches the stream's own sockets instead of matching text in the log, which is what was fooling it.
- **VRAM was double-counted** — shared graphics memory was being added to the dedicated figure, so the dashboard over-reported usage.
- **One bad frame no longer decides a long session.** A single stall could drag a whole session's grade down regardless of how the rest of it ran.

## Notes

- Everything in this release is host-side. ArtMoon needs no update to use any of it.
- Control is bumped to 1.3.0 in lockstep so Server and Control report the same version.
- Windows Defender may flag the download as unsafe, Windows doesn't know what ArtLight is yet
- Code signing via SignPath Foundation is being set up; until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
