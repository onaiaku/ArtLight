# ArtLight 1.1.0 - 2026-09-02

Developed by onaiaku & Rias.

## Fixed

- Game library sync now writes to ArtLight Server's own apps.json. Previously, "Sync Now" could report success while writing every game into a leftover legacy install (e.g. an old Apollo folder), because server discovery didn't know the nested `ArtLight\ArtLight Server` layout. Discovery now checks the nested layout and reads the install location from the registry, so it works at any install path. (4432f9f7)
- Combined installer no longer installs Control to `C:\program` when the path contains spaces; the "Launch ArtLight Control" checkbox now works as expected. (fe56115e)
- Installed build now reports its true version instead of a hardcoded `0.1.0` fallback, which caused false "update available" nags on non-release builds. (cd83ffa1)

## Changed

- A stream connect now shows **one** tray notification — "App launched (Device connected)" — instead of two separate toasts seconds apart. (e641d68d)

## Added

- Changelog panel on the web UI Overview page, so update notes appear in-app instead of only on GitHub. (9ad3f330)

## Notes

- Windows Defender may flag the download as unsafe, Windows doesn't know what ArtLight is yet
- Code signing via SignPath Foundation is being set up; until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
