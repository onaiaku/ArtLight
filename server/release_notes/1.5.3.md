# ArtLight 1.5.3 - 2026-10-10

Developed by onaiaku & Rias.

## Fixed

- **ArtLight's own virtual gamepad driver now installs.** It has shipped since 1.5.1 and has never once installed, because a driver package installs only when its catalogue is signed, and ours was not signed. The driver package now carries its own signing certificate and is signed, so it installs on a clean machine and the virtual controller works without anything else being present.
- **The driver a machine already has is left alone.** If a ViGEmBus new enough to use is already installed, it is untouched.

## Notes

- ViGEmBus is still offered on the install screen, ticked by default, so controller input keeps working on machines where you would rather not install ArtLight's own driver.
- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
