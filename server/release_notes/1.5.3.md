# ArtLight 1.5.3 - 2026-10-10

Developed by onaiaku & Rias.

## Added

- **ArtLight's own virtual gamepad driver now installs.** The driver has shipped since 1.5.1 and never once installed, because a driver package installs only when its catalogue is signed and ours was not signed in a way Windows would accept. The package now carries its own signing certificate and the installer trusts it, so the driver installs on a clean machine and the virtual controller works without anything else being present.

## Fixed

- **Automatic uses ArtLight's own driver first** when a machine has both it and ViGEmBus. ViGEmBus is retired upstream (end of life, late 2023), so it is the fallback now rather than the first choice.
- **ViGEmBus is no longer offered or bundled by the installer.** It was a tick box on the install screen and an install step behind it; both are gone.
- **The installer no longer leaves a USBip shortcut on your desktop.** The USB/IP client ArtLight bundles creates one by default, and ArtLight now tells its installer not to.
- **A second device now sees what the host is actually streaming.** If a PC is already streaming Desktop, opening ArtMoon on another device now shows that stream — the running app, the STREAMING badge, and Resume and Stop — instead of showing the machine as idle. Any paired device you open sees what the host is really doing.

## Notes

- A ViGEmBus already on a machine is not removed. ArtLight simply no longer installs or offers it, and prefers its own driver wherever that driver is present.
- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
