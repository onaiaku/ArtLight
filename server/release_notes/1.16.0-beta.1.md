# ArtLight Server 1.16.0-beta.1 - 2026-05-28

Notice: ArtLight Server may trigger false-positive antivirus alerts. Details and workarounds are documented here: https://github.com/onaiaku/ArtLight/issues/59

## Changes
- Synced ArtLight Server with the current Sunshine upstream so the project can keep pace while Apollo has not received updates recently; going forward ArtLight Server will inherit Sunshine changes in addition to Vibeshine changes.
- Added the bundled experimental ArtLight Server Display Driver as an opt-in Windows display driver, while keeping SudoVDA as the default. It may improve smoothness on virtual displays and retains EDID and HDR settings.
- Added a Dashboard warning when the saved display snapshot is stale and should be recreated.

## Fixes
- Stabilized bundled virtual display creation, recovery, cleanup, HDR activation, probe handling, and stream teardown.
- Fixed WebRTC browser stream latency capping and synchronized capture teardown during video reinitialization.
- Fixed Moonlight pairing cleanup and Web API CSRF mutations.
- Fixed AV1 HDR advertisement, HDR capability probing, and startup encoder probing on Windows.
- Fixed HEVC Main10 and AV1 10-bit handling with NVENC API 12.1 drivers by preserving the legacy bit-depth layout expected by older runtimes.
- Fixed HDR and SDR setup so AV1 10-bit fallback, launch HDR intent, and delayed display-helper re-applies keep the intended color mode.
- Fixed stream-end display restoration to prefer the golden snapshot before previous session state, avoiding stale restores that could leave secondary monitors disabled.
- Fixed display capture overrides so physical output selections are preserved when display configuration is disabled.
