# ArtLight Server 1.0.0 - 2026-09-01

The first release of ArtLight. ArtLight is self-hosted game streaming for Windows: the server (a fork of Sunshine) and the Control companion app, installed together by a single installer.

Developed by onaiaku & Rias.

## Highlights

- Single combined installer (`ArtLight Setup.exe`): one wizard, one elevation, installs both ArtLight Server and ArtLight Control. The server lands in `ArtLight\ArtLight Server`, Control next to it in `ArtLight\ArtLight Control`.
- Control auto-installs with the server by default (untick on the options page for a server-only install), and upgrades automatically when a newer version is embedded.
- Selective uninstall: one uninstaller removes Server and/or Control based on checkboxes, with the choices surviving elevation.
- The bundled virtual display driver ships pre-signed (pinned Nonary/libvirtualdisplay release); the installer itself is reproducible from this public repository.
- ArtLight Control detects the server automatically, shows stream statistics, and provides session control from the tray.
- Update checks point at this repository's releases (server web UI and Control both), disabled until an update is actually published.
- Fresh Web UI as the default, with ArtLight branding throughout.

## Notes

- ArtLight Server is a fork of Sunshine (https://github.com/LizardByte/Sunshine, GPL-3.0). ArtLight Control is a fork of StreamTweak by FoggyBytes (https://github.com/FoggyBytes/StreamTweak, GPL-3.0).
- Code signing via SignPath Foundation is being set up; until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
