# ArtLight 1.5.2 - 2026-10-10

Developed by onaiaku & Rias.

## Fixed

- **Controller input works again.** 1.5.1 put ArtLight's own virtual gamepad driver back into the installer, and it still did not install: a driver package installs only when its catalogue is signed, and ArtLight has no code-signing certificate. The installer now offers and installs **ViGEmBus** - the virtual gamepad driver signed by its authors - ticked by default on the install screen. That is what creates the virtual controller, and without it controller input never reaches a stream.
- **A ViGEmBus you already run is left alone.** If the machine already has ViGEmBus 1.17 or newer, the installer finds it and does nothing rather than installing over a driver other software may already be using.

## Notes

- ArtLight's own virtual gamepad driver is still shipped, and still preferred on machines that have it. It is unchanged in 1.5.2. What changed is that the installer no longer depends on it to give you working controllers.
- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- **Signing:** ArtLight has no code-signing certificate, so downloads are unsigned. SignPath Foundation declined the project and the paid tier is out of reach for now. Until that changes, verify downloads by building from source or checking CI artifacts against this repository.
