# ArtLight 1.5.6 - 2026-10-14

Developed by onaiaku & Rias.

## Added

- **ArtLight now installs on Fedora.** Fedora 43 and 44 are supported from our own repository, so there is no longer any need to build the server yourself to run it there. Enable it once with `sudo dnf copr enable onaiaku/artlight`, then `sudo dnf install artlight` as usual. The Windows installer and the Arch package are published for this release exactly as they were before.

## Fixed

- **The display comes back correctly once a stream ends.** On Linux the restore step could refuse the display it had been handed instead of accepting it, which left the desktop in the wrong state after a session finished until it was set up again by hand.
- **A controller module that is installed and working is no longer reported as missing.** The DualSense module check on Linux read a healthy module as unavailable, which sent people looking for a fault that was not there.

## Notes

- Windows Defender may flag the download as unsafe; Windows does not know what ArtLight is yet.
- Code signing via SignPath Foundation is being set up. Until the first signed build, verify downloads by building from source or checking CI artifacts against this repository.
